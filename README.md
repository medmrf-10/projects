# المشاريع التفاعلية والقصص البصرية

يضم هذا المستودع العام المشاريع التفاعلية والقصص المرئية المنشورة مباشرة عبر خدمة الصفحات الثابتة لسهولة الوصول والمشاركة عبر الروابط المباشرة.

## قائمة المشاريع المنشورة

1. المشروع رقم 1 — قصة التنمّر من منظور علم النفس:
   - النسخة السينمائية المتصلة الحديثة (مشاهد حية مستمرة وشخصيات متحركة متتابعة داخل المشهد الواحد).
   - النسخة التفاعلية السابقة المحفوظة للمقارنة المباشرة.
